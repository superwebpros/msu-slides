### What's a Retrospective?

<div style="font-size: 22px; margin: 20px auto 0 auto;">
Your team looks back at how it worked, and picks what to change
</div>

<div style="font-size: 18px; max-width: 900px; margin: 24px auto 0 auto;">

| | |
|---|---|
| **Keep Doing** | What already works |
| **More Of** | Something you do occasionally and should do consistently |
| **Less Of** | Still worth doing, but costing more than it returns |
| **Start Doing** | Something the team doesn't do yet |
| **Stop Doing** | Something that has outlived the problem it solved |

</div>
